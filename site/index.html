Predella Beta

A gallery, viewer and note editor for your folders. See your newest files as big pictures, open anything without leaving the app, and write and link your notes, all in one window.

A predella is the row of small paintings beneath the main panel of an altarpiece: the gallery under the big picture.

Download for Linux Version 0.3.3 · Free · Ubuntu, Debian, Linux Mint, Pop!_OS · Fedora · All versions

What it does

  • A gallery of your newest filesReal previews: pictures (iPhone HEIC too), PDFs, web pages, spreadsheets, Word and PowerPoint files, text.
  • A viewer for all of themZoom, full screen, and stepping through a folder.
  • A Markdown note editorLive formatting, autosave, [[links]], "Linked from", and a graph of how your notes connect.
  • Find thingsSearch inside your files, a folder view with sorting, and a split view for two files side by side.
  • HomeOne picture tile per project folder, with where each one stands if you or your AI assistant keep a CurrentState.md in it.

Install

  1. Download predella_0.3.3_amd64.deb with the button above.
  2. Double-click it. App Center opens: click Install.
  3. Open Predella from your apps. The first time, it asks which folders to show.

Or download and install it in one go: paste this into a terminal (it asks for your password).

cd ~/Downloads && wget -O predella_0.3.3_amd64.deb https://github.com/predella-app/predella/releases/download/v0.3.3/predella_0.3.3_amd64.deb && sudo apt install ./predella_0.3.3_amd64.deb

On Fedora: download predella-0.3.3.x86_64.rpm and double-click it, or run:

cd ~/Downloads && curl -fLo predella-0.3.3.x86_64.rpm https://github.com/predella-app/predella/releases/download/v0.3.3/predella-0.3.3.x86_64.rpm && sudo dnf install ./predella-0.3.3.x86_64.rpm

Predella tells you when a new version is out (Help → Check for Updates). Click Install and Restart: it downloads it, checks it, asks for your password, installs it and restarts. Your folders and settings stay.

With an AI assistant

If an AI assistant keeps notes on your projects, Predella shows where each one stands on its Home tile: what's happening now, countdowns to dates, and what's waiting on you. Paste this into your assistant's instructions (AGENTS.md for most coding assistants, CLAUDE.md for Claude Code):

Keep a file named CurrentState.md in each project folder:
- "## Now": one or two bullets on what is happening right now.
- "## Open items": one bullet per open task. Put its date in it when it has one (2026-12-04).
- When a task needs me, write "waiting on me" in that bullet.
- Only what is true now. Move finished items to Completed.md in the same folder.

Privacy

Everything stays on your computer. No account, no tracking, no data collection. Predella reads the folders you pick and changes nothing in them, except a note's text when you edit it. It contacts only GitHub, to see whether a newer version exists. This website sets no cookies and loads nothing from anywhere else.
